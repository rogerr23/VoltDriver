## Padrão para as próximas tasks

Cada task deve:

1. ser explicada antes da implementação;
2. ter escopo pequeno e uma camada claramente identificada;
3. registrar aqui o que foi criado ou alterado;
4. informar as verificações executadas;
5. terminar com commit próprio;
6. manter backend e frontend em commits separados.

O arquivo da task acompanha o mesmo commit da implementação. O índice deve ser atualizado no mesmo momento.
